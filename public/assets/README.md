# Noolinnayam by Divya — Image Assets Guide

Drop your real photography into these folders to replace the placeholders across the website.

---

## 📁 Folder Architecture & Recommended Image Specs

### 1. `/public/assets/hero/`
- **`desktop-hero.jpg`** — Full-width homepage hero background for desktop (`1920×1080px` or `2560×1440px`, Landscape)
- **`mobile-hero.jpg`** — Optimized crop for mobile screens (`750×1200px` or `1080×1920px`, Portrait)

---

## ⚡ Supported Formats
You can use `.jpg`, `.jpeg`, `.png`, `.webp`, or `.avif`. Next.js automatically optimizes and serves them as WebP/AVIF to visitors.
